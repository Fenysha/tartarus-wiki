## Общая информация


В данном разделе архива собраны записи и сведения о доменах, в которых может быть проведена симуляция.

Каждый раздел этой части архива содержит полную информацию о соответствующем домене, включая его содержимое, особенности среды и предполагаемый сценарий симуляции.

Ниже приведён перечень действующих доменов, доступных для загрузки:

* **Trainstation (The Final Trainstation)** — планетарный домен, представляющий собой сюжетную симуляцию, целью которой является транспортировка определённого груза. События разворачиваются на неназванной планете, где подопытные получают под управление активный подвижной состав, модифицированный для дальних перемещений. Подробнее о данном домене можно ознакомиться в [соответствующем разделе](trainstation).
