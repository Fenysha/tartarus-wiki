## How to Contribute

Anyone can contribute:

1. **Open repository** on [GitHub](https://github.com/TeshariEnjoer/tartarus-wiki)
2. **Create Pull Request** with your changes
3. **Discuss** proposed changes in comments
4. **Merge** after approval

Documents are written in **Markdown** and automatically published.
