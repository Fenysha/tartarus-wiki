## Внести запись

Порядок публикации данных:

1. Откройте [репозиторий](https://github.com/TeshariEnjoer/tartarus-wiki).
2. Создайте Pull Request с изменениями.
3. Обсудите запись в комментариях.
4. После проверки запись будет опубликована.

Документы хранятся в **Markdown** и публикуются автоматически.

## Структура файловой системы

- **`/docs/`** — основные документы и правила
- **`/guides/`** — гайды и туториалы  
- **`/lore/`** — информация о мире и истории
- **`/events/`** — события и анонсы
