## Recommended template

```md
<div class="doc-header">
  <div class="doc-header-item">
    <span>Security level</span>
    <strong>Classification D</strong>
  </div>
  <div class="doc-header-item">
    <span>Threat</span>
    <strong>Low</strong>
  </div>
  <div class="doc-header-item">
    <span>Path</span>
    <strong>/docs/example/</strong>
  </div>
</div>
```

## Storage principle

Paths are kept in the following format:

```text
/docs/some_docs/...
```

This provides flexibility for future migration to more complex structures.
